This can be achieved by doing regularization.</p><p><strong>There are two types of regularization as follows:</strong></p><ul><li><strong>L1 Regularization or Lasso Regularization</strong></li><li><strong>L2 Regularization or Ridge Regularization</strong></li></ul><p><strong>Planning your move into AI?</strong></p><p>No matter which tech domain you work in today, with your effort, you can transition to these roles:</p><ul><li>AI Engineer</li><li>Forward Deployed Engineer</li><li>AI Agent Engineer</li><li>Harness Engineer</li><li>Voice AI Engineer</li><li>AI Architect</li><li>LLM Engineer</li><li>LLM Inference Engineer</li><li>Gen AI Engineer</li><li>MLOps Engineer</li><li>ML Engineer</li><li>Deep Learning Engineer</li></ul><p>Our <a target="_blank" rel="noopener noreferrer" href="https://outcomeschool.com/program/ai-and-machine-learning">AI and Machine Learning Program</a> at Outcome School takes you there.</p><h2 id="l1-regularization-or-lasso-regularization"><a href="#l1-regularization-or-lasso-regularization" aria-hidden="true" tabindex="-1"></a>L1 Regularization or Lasso Regularization</h2><p>L1 Regularization or Lasso Regularization adds a penalty to the error function. But the penalty here is the sum of the <strong>squared</strong> values of weights.</p><p>Similar to L1, in L2 also, <code>p</code> is the tuning parameter which decides how much we want to penalize the model.</p><p>This is <strong>Regularization</strong>.</p><p>Apart from L1 and L2, there are other regularization techniques as well. L1, or Lasso, uses the sum of the absolute values of the weights. L2, or Ridge, uses the sum of the squared values of the weights.</p><h3 id="what-does-the-tuning-parameter-p-do-in-regularization"><a href="#what-does-the-tuning-parameter-p-do-in-regularization" aria-hidden="true" tabindex="-1"></a>What does the tuning parameter p do in regularization?</h3><p>The tuning parameter <code>p</code> decides how much we want to penalize the model. It plays the same role in both L1 and L2 regularization, controlling the strength of the penalty added to the error function.</p><h3 id="why-does-regularization-help-with-overfitting"><a href="#why-does-regularization-help-with-overfitting" aria-hidden="true" tabindex="-1"></a>Why does regularization help with overfitting?</h3><p>Overfitting happens when a model learns the detail and noise in the training data, which hurts its performance on new data. A good model does not give more weight to a particular feature, and its weights are evenly distributed. Regularization helps achieve this by penalizing the weights.</p><h3 id="are-l1-and-l2-the-only-regularization-techniques"><a href="#are-l1-and-l2-the-only-regularization-techniques" aria-hidden="true" tabindex="-1"></a>Are L1 and L2 the only regularization techniques?</h3><p>No. Apart from L1 and L2, there are other regularization techniques as well.
