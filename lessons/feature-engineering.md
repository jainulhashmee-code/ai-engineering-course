# What is Feature Engineering in Machine Learning?

<img alt="Feature Engineering for Machine Learning" src="images/feature-engineering.png"/><p>Feature Engineering is the process of using domain knowledge of the data to create features that make Machine Learning algorithms work. If it is done correctly, it increases the predictive power of the model.</p><p>In this blog, we will learn about the Feature Engineering for Machine Learning.</p><p>I am <strong>Amit Shekhar</strong>, Founder @ <a target="_blank" rel="noopener noreferrer" href="https://outcomeschool.com">Outcome School</a>, I have taught and mentored many developers, and their efforts landed them high-paying tech jobs, helped many tech companies in solving their unique problems, and created many open-source libraries being used by top companies. I am passionate about sharing knowledge through open-source, blogs, and videos.</p><p>I teach <a target="_blank" rel="noopener noreferrer" href="https://outcomeschool.com/program/ai-and-machine-learning">AI and Machine Learning</a> at Outcome School.</p><p>Let&#x27;s get started.</p><p><strong>Feature Engineering is an art</strong></p><p>Feature engineering is the process of using <strong>domain knowledge</strong> of the data to create features that make <a target="_blank" rel="noopener noreferrer" href="machine-learning.md">machine learning</a> algorithms work. If feature engineering is done correctly, it increases the predictive power of machine learning algorithms by creating features from raw data that help facilitate the machine learning process. Feature Engineering is an art.</p><p><strong>Steps which are involved while solving any problem in machine learning are as follows:</strong></p><ul><li>Gathering data.</li><li>Cleaning data.</li><li><strong>Feature engineering</strong>.</li><li>Defining model.</li><li>Training, testing model and predicting the output.</li></ul><p>Feature engineering is the most important art in machine learning which creates the huge difference between a good model and a bad model. Let&#x27;s see what feature engineering covers.</p><p>Suppose, we are given a data &quot;flight date time vs status&quot;. Then, given the date-time data, we have to predict the status of the flight.</p><table><thead><tr><th align="left"></th><th align="left">Date_Time_Combined</th><th align="left">Status</th></tr></thead><tbody><tr><td align="left">0</td><td align="left">2018-02-14 20:40</td><td align="left">Delayed</td></tr><tr><td align="left">1</td><td align="left">2018-02-15 10:30</td><td align="left">On Time</td></tr><tr><td align="left">2</td><td align="left">2018-02-14 07:40</td><td align="left">On Time</td></tr><tr><td align="left">3</td><td align="left">2018-02-15 18:10</td><td align="left">Delayed</td></tr><tr><td align="left">4</td><td align="left">2018-02-14 10:20</td><td align="left">On Time</td></tr></tbody></table><p>As the status of the flight depends on the hour of the day, not on the date-time. Suppose we are given the latitude, longitude and other data with the given label <code>Price_Of_House</code>. We need to predict the price of the house in that area. The latitude and longitude are not of any use if they are alone. So, here we will use the <strong>crossed column</strong> feature engineering. We will combine the latitude and the longitude to make one feature. Combining into one feature will help the model learn better.</p><p>Here, combining two features to create one useful feature is the feature engineering.</p><p>Sometimes, we use the <strong>bucketized column</strong> feature engineering. Suppose we are given a data in which one column is the age and the output is the classification(X, Y, Z). By seeing the data, we realized that the output(X, Y, Z) is dependent on the age-range like 11-20 years age-range output to X, 21-40 years output to Y, 41-70 years output to Z. Here, we will create 3 buckets for the age-range 11-20, 21-40 and 41-70. We will create the new feature which is the bucketized column <code>Age_Range</code> having the numerical values 1, 2 and 3 where 1 is mapped to the bucket 1, 2 is mapped to the bucket 2 and 3 is mapped to the bucket 3.</p><p>Here, creating <code>Age_Range</code> bucket is the feature engineering.</p><p>We have a detailed blog on <a target="_blank" rel="noopener noreferrer" href="one-hot-encoding.md">One-hot Encoding</a> that explains how we turn categories into numbers without adding a fake order.</p><p><strong>A quick note for you</strong></p><p>No matter which tech domain you work in, get familiar with these topics:</p><ul><li>LLM</li><li>RAG</li><li>MCP</li><li>Agent</li><li>Fine-tuning</li><li>Quantization</li></ul><p>We put it all together in one video:</p><p><a target="_blank" rel="noopener noreferrer" href="https://www.youtube.com/watch?v=lnfWvX66FUk">AI Engineering Explained: LLM, RAG, MCP, Agent, Fine-Tuning, and Quantization</a></p><p>No need to stop reading - bookmark it and watch later when you get time. As the feature which is not related degrade the performance of the model.</p><p><strong>Now, the steps to do feature engineering are as follows:</strong></p><ul><li>Brainstorm features.</li><li>Create features.</li><li>Check how the features work with the model.</li><li>Start again from first until the features work perfectly.</li></ul><p>This is what we do in the feature engineering.
